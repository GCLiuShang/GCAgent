# GCAgent 0.0.1

首个可运行的研究原型。

## 包含

- Android 端 Compose UI：首页、企鹅备份页、资料库、设置、液态玻璃底栏、开屏动画；
- LSPosed 观察链路：联系人、会话、消息元数据与部分媒体；
- root + VirtualDisplay 采集链路；
- 本地 SQLite：用户与会话索引；
- 电脑端 v1 framed-JSON 接收器与测试；
- 开屏动画生成源（Three.js + Puppeteer/FFmpeg）。

## 当前限制

- 大量规划功能尚未实现；
- 企鹅客户端适配版本为 **9.3.75**，升级后可能失效；
- 电脑端数据库、命令下发、鉴权仍是设计阶段；
- 微信、电脑组网、本地 AI 尚未实现。

## 使用范围

仅用于个人设备上的个人数据备份与研究。请自行评估并承担使用风险。

## 校验

APK：`GCAgent-0.0.1-debug.apk`（debug 签名，仅供测试）。
